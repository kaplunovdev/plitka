Приложение «Plitka» (далее — «Приложение», «мы», «наш») уважает конфиденциальность пользователей. Настоящая Политика конфиденциальности объясняет, какие данные собираются, как они используются и защищаются.

1. Общие положения

Настоящая Политика конфиденциальности применяется к приложению «Plitka». Используя Приложение, вы соглашаетесь с условиями данной политики.

2. Сбор данных

Приложение не собирает персональные данные пользователей, включая адрес электронной почты, имя, телефон или другие личные сведения.

Для работы с платёжными системами (RuStore, AppGallery и другими) используется технический идентификатор, предоставляемый соответствующим магазином приложений. Этот идентификатор не является персональными данными и используется только для проверки статуса покупки.

3. Локальные данные

Все пользовательские данные, связанные с работой приложения, сохраняются только на устройстве пользователя:

  • Расчёты плитки и материалов
  • Замеры помещений
  • Финансовые расчёты
  • Настройки приложения
  • Архив расчётов

Эти данные не передаются разработчику и не хранятся на серверах разработчика.

4. Облачная синхронизация (опционально)

Приложение предоставляет возможность резервного копирования и синхронизации данных через облачные хранилища третьих лиц:

  • Яндекс.Диск — для хранения резервных копий данных пользователя

При включении синхронизации данные передаются в выбранное облачное хранилище и защищаются в соответствии с политикой конфиденциальности соответствующего провайдера:

  • Политика конфиденциальности Яндекса

Разработчик не имеет доступа к данным в облачных хранилищах пользователей и не обрабатывает их.

Синхронизация является опциональной функцией и может быть включена или выключена пользователем в любой момент в настройках приложения.

5. Покупки и подписки

Полная версия приложения может быть приобретена через платёжные системы магазинов приложений:

  • RuStore — для устройств с установленным магазином RuStore
  • Huawei AppGallery — для устройств Huawei
  • Другие платёжные системы в зависимости от платформы распространения

Обработка платежей выполняется соответствующими платёжными сервисами. Приложение не получает и не хранит данные банковских карт, номеров счетов или другую финансовую информацию пользователей.

Статус подписки проверяется через API соответствующего магазина приложений и не передаётся на серверы разработчика.

6. Экспорт данных

При экспорте расчётов файлы формата PDF или CSV создаются локально на устройстве пользователя. Пользователь самостоятельно решает, как использовать или передавать эти файлы.

7. Реклама

Приложение не содержит рекламы и не использует рекламные SDK.

8. Безопасность

Мы принимаем разумные технические и организационные меры для защиты данных пользователей. Все данные хранятся локально на устройстве пользователя или в выбранном пользователем облачном хранилище.

9. Права пользователей

В соответствии с законодательством Российской Федерации о персональных данных пользователь имеет право:

  • отказаться от использования функций полной версии приложения
  • отключить облачную синхронизацию в любой момент
  • удалить данные из облачного хранилища через интерфейс соответствующего провайдера

10. Детская аудитория

Рейтинг приложения — 3+. Приложение не предназначено для сбора персональных данных детей и не осуществляет целенаправленный сбор информации о детях.

11. Изменения политики

Мы можем обновлять настоящую Политику конфиденциальности. Обновлённая версия будет опубликована на данной странице.
