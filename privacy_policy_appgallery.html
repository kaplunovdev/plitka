Приложение «Plitka» (далее — «Приложение», «мы», «наш») уважает конфиденциальность пользователей. Настоящая Политика конфиденциальности объясняет, какие данные собираются, как они используются и защищаются.

1. Общие положения

Настоящая Политика конфиденциальности применяется к приложению «Plitka». Используя Приложение, вы соглашаетесь с условиями данной политики.

2. Сбор данных

Приложение собирает адрес электронной почты пользователя только в случае регистрации для покупки или активации полной версии приложения.

Электронная почта используется исключительно для:

  • создания уникального идентификатора пользователя
  • проверки и хранения статуса подписки
  • восстановления доступа к полной версии приложения при смене устройства

Приложение не запрашивает имя, телефон, адрес или другие персональные данные.

3. Локальные данные

Все пользовательские данные, связанные с работой приложения, сохраняются только на устройстве пользователя:

  • Расчёты работ и материалов
  • Финансовые расчёты
  • Настройки приложения
  • Архив расчётов

Эти данные не передаются разработчику и не хранятся на сервере.

4. Серверная проверка подписки

Для проверки статуса подписки используется сервер приложения.

На сервер передаются и хранятся следующие данные:

  • адрес электронной почты пользователя
  • технический идентификатор пользователя
  • статус подписки
  • тип подписки (месячная, годовая или бессрочная)
  • дата окончания подписки

Сервер размещён на виртуальном сервере (VPS) у хостинг-провайдера Jino.ru и использует backend-платформу PocketBase для хранения данных.

5. Покупки и подписки

Полная версия приложения может быть приобретена через различные платежные системы в зависимости от версии приложения и платформы распространения.

  • В версии приложения, распространяемой через Huawei AppGallery, покупки могут обрабатываться встроенной платежной системой магазина приложений.
  • В некоторых версиях приложения пользователь может быть перенаправлен на внешнюю страницу оплаты для оформления подписки через платёжную систему ЮKassa.

Обработка платежей выполняется соответствующими платежными сервисами. Приложение не получает и не хранит данные банковских карт, номеров счетов или другую финансовую информацию пользователей.

6. Экспорт данных

При экспорте расчётов файлы формата PDF или CSV создаются локально на устройстве пользователя. Пользователь самостоятельно решает, как использовать или передавать эти файлы.

7. Реклама

Приложение не содержит рекламы и не использует рекламные SDK.

8. Безопасность

Мы принимаем разумные технические и организационные меры для защиты данных пользователей. Доступ к серверу ограничен и используется только для хранения и проверки статуса подписки.

9. Права пользователей

В соответствии с законодательством Российской Федерации о персональных данных пользователь имеет право:

  • запросить информацию о хранимых данных
  • запросить исправление данных
  • запросить удаление данных
  • отказаться от использования функций полной версии приложения

10. Детская аудитория

Рейтинг приложения — 3+. Приложение не предназначено для сбора персональных данных детей и не осуществляет целенаправленный сбор информации о детях.

11. Изменения политики

Мы можем обновлять настоящую Политику конфиденциальности. Обновлённая версия будет опубликована на данной странице.
