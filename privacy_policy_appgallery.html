Политика конфиденциальности

Дата последнего обновления: 25 февраля 2026 г.

Приложение «Плитка Калькулятор» (далее — «Приложение», «мы», «наш») уважает конфиденциальность пользователей. Настоящая Политика конфиденциальности объясняет, какие данные собираются, как они используются и защищаются.

1. Общие положения

Настоящая Политика конфиденциальности применяется к приложению «Плитка Калькулятор». Используя Приложение, вы соглашаетесь с условиями данной политики.

2. Сбор данных

Приложение собирает только адрес электронной почты пользователя. Электронная почта используется исключительно для синхронизации данных в облачном хранилище.

Все остальные функции приложения работают полностью локально на вашем устройстве без передачи данных на внешние серверы.

3. Локальные данные

Приложение сохраняет следующие данные только на вашем устройстве:

  • Расчёты плитки и материалов
  • Замеры помещений
  • Финансовые расчёты
  • Настройки приложения
  • Архив расчётов

Эти данные не передаются разработчику или третьим лицам.

4. Облачная синхронизация

При использовании функции облачной синхронизации:

  • Для синхронизации используется только ваш адрес электронной почты
  • Данные шифруются перед отправкой в облачное хранилище
  • Доступ к вашим данным имеет только владелец аккаунта
  • Разработчик не имеет доступа к вашим данным

5. Резервное копирование

При использовании функции резервного копирования:

  • Данные шифруются перед отправкой в облачное хранилище
  • Доступ к резервным копиям имеет только владелец аккаунта
  • Разработчик не имеет доступа к вашим резервным копиям

6. Экспорт данных

При экспорте расчётов в PDF или CSV файлы создаются локально на вашем устройстве. Вы самостоятельно решаете, с кем поделиться этими файлами.

7. Покупки в приложении

Покупки в приложении обрабатываются через платёжные системы Google Play или Huawei AppGallery. Мы не храним данные ваших платёжных карт или банковских счетов.

8. Реклама

Приложение не содержит рекламы и не использует рекламные SDK.

9. Сторонние сервисы

Приложение может использовать следующие сторонние сервисы:

  • Google Sign-In — для аутентификации по электронной почте
  • Google Drive / Huawei Cloud — для облачной синхронизации данных (опционально)

Эти сервисы регулируются собственными политиками конфиденциальности соответствующих компаний.

10. Безопасность

Мы применяем разумные меры для защиты ваших данных. Однако ни одно приложение не может гарантировать абсолютную защиту. Рекомендуем регулярно создавать резервные копии важных данных.

11. Права пользователей

Вы имеете право:

  • Удалить все данные приложения путём удаления приложения с устройства
  • Отказаться от использования функций облачной синхронизации
  • Запросить удаление ваших данных из облачного хранилища
  • Связаться с нами по вопросам обработки данных

12. Детская аудитория

Приложение предназначено для общей аудитории и не направлено на детей младше 13 лет. Мы сознательно не собираем данные детей.

13. Изменения политики

Мы можем обновлять эту Политику конфиденциальности. При значительных изменениях мы уведомим вас через приложение или разместим новую версию на данной странице. Рекомендуем периодически проверять обновления.
