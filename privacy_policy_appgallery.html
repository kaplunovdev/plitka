Политика конфиденциальности

Дата последнего обновления: 25 февраля 2026 г.

Настоящая Политика конфиденциальности описывает порядок сбора, использования и хранения данных пользователей мобильного приложения «Plitka» (далее — «Приложение»).

1. Оператор данных

Оператором персональных данных является разработчик приложения ALEXSOFT (далее — «Оператор»).

2. Какие данные могут обрабатываться

В зависимости от использования функций Приложения могут обрабатываться следующие данные:

  • Адрес электронной почты (при регистрации)
  • Уникальный идентификатор пользователя (User ID)
  • Данные о статусе подписки и пробного периода
  • Файлы пользовательских данных (резервные копии JSON)

Без использования регистрации и облачной синхронизации данные сохраняются исключительно на устройстве пользователя.

3. Цели обработки данных

  • Регистрация и аутентификация пользователя
  • Облачная синхронизация и резервное копирование
  • Восстановление доступа к аккаунту
  • Управление пробным периодом и подпиской
  • Обеспечение корректной работы Приложения

4. Используемые сторонние сервисы

4.1 Supabase

Для аутентификации и облачного хранения данных используется платформа Supabase.

Supabase выступает в роли обработчика данных (data processor), обеспечивая техническую инфраструктуру хранения и обработки информации. Регион хранения данных определяется конфигурацией проекта.

4.2 Huawei AppGallery

Покупки внутри приложения и подписки обрабатываются через Huawei AppGallery.

Платёжные данные (включая данные банковских карт) не передаются Оператору и не хранятся в Приложении.

5. Передача данных третьим лицам

Передача данных осуществляется исключительно техническим поставщикам услуг, необходимым для работы Приложения (включая Supabase и Huawei AppGallery), в объёме, необходимом для предоставления функций Приложения.

Продажа персональных данных третьим лицам не осуществляется.

6. Хранение данных

Данные хранятся в течение срока использования аккаунта пользователем либо до момента удаления аккаунта по запросу пользователя.

7. Права пользователя

Пользователь имеет право:

  • Запросить информацию о своих данных
  • Запросить исправление или удаление данных
  • Удалить аккаунт и связанные с ним данные
  • Отозвать согласие на обработку данных

8. Безопасность

Оператор принимает разумные технические и организационные меры для защиты данных от несанкционированного доступа, изменения или уничтожения.

9. Детская аудитория

Приложение не предназначено для целенаправленного сбора персональных данных детей. Мы не осуществляем осознанный сбор данных лиц младше возраста, установленного применимым законодательством.

10. Изменения политики

Политика конфиденциальности может обновляться. Актуальная версия размещается по указанному адресу публикации.
